# ILP TAB — Ivoire Luxe Pressing

Application Web de gestion interne.

## 🚀 Déploiement automatique

Chaque push sur `main` déclenche un déploiement automatique sur GitHub Pages via GitHub Actions.

**URL de production :** `https://<username>.github.io/ilp-tab/`

## 💻 Développement local

```bash
npm install
npm run dev
```

## 🏗️ Build de production

```bash
npm run build
npm run preview
```

## 📱 Installation PWA

L'application est installable sur tous les appareils (Android, iOS, PC).
